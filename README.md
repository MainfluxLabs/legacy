# legacy

A community archive of Mainflux components that are no longer maintained by the core team.

## What's here

Code that was part of the [Mainflux](https://github.com/MainfluxLabs/mainflux) platform but has been superseded or dropped from the main repository. It is published here so the community can continue using or maintaining it.

## Maintenance

This code is **not maintained by the Mainflux core team**. It is provided as-is. Community contributions and forks are welcome.
